💻 Aula 18: Servidor de Arquivos: FSRM (Cotas e Triagem)
Nesta etapa, foi implantada a Role File Server Resource Manager (FSRM) para governança, controle de capacidade e proteção contra arquivos não autorizados.

📋 Checklist de Atividades (Tasks)
[x] 1. Instalação da Role FSRM: Adição da função de Gerenciador de Recursos do Servidor de Arquivos via Server Manager.

[x] 2. Configuração de Cotas de Disco (Quotas): Aplicação de limites rígidos (Hard Quota) e flexíveis (Soft Quota) para controle de armazenamento por usuário ou pasta.

[x] 3. Implementação de Triagem de Arquivos (File Screening): Criação de regras para bloqueio automático de extensões de risco (ex: .exe, .mp3, arquivos de vídeo ou ransomware).

[x] 4. Validação e Notificações: Teste de gravação de arquivos bloqueados para homologação do alerta e travamento de armazenamento.
