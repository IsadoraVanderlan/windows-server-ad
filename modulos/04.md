## 💻 Aula 04: Conexão de Área de Trabalho Remota (RDP)

Nesta etapa, foi configurado o acesso remoto ao Windows Server via **Remote Desktop Protocol (RDP)**, incluindo o ajuste avançado da rede virtual no Hyper-V para garantir conectividade estável.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Habilitação do RDP no Windows Server:** Ativação da permissão de conexões remotas nas propriedades do sistema e liberação das regras correspondentes no **Windows Firewall**.
- [x] **2. Solução de Problemas de Redes Virtuais:** Identificação de falhas de atribuição via DHCP/APIPA (`169.254.x.x`) e criação de um **Comutador Virtual Interno (Virtual Switch)** dedicado.
- [x] **3. Configuração de Endereçamento IPv4 Estático:**
  - **Host (PC Físico):** Definição manual do IP estático na interface virtual (`192.168.50.1/24`).
  - **VM (Windows Server):** Atribuição de IP fixo (`192.168.50.2/24`) com gateway para comunicação ponto a ponto isolada.
- [x] **4. Validação da Conexão:** Teste de conectividade ICMP (`ping`) e estabelecimento de sessão remota com sucesso utilizando a Conexão de Área de Trabalho Remota.
