## 💻 Aula 14: Instalação e Configuração do Servidor DHCP

Nesta etapa, foi realizada a implantação do serviço **DHCP Server** no Windows Server para automação do endereçamento IP da rede interna.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Instalação da Role DHCP Server:** Adição da função de Servidor DHCP através do Server Manager e conclusão do assistente de pós-instalação.
- [x] **2. Autorização do Servidor DHCP no AD DS:** Liberação do servidor DHCP no Active Directory para execução autorizada no ambiente de domínio.
- [x] **3. Criação e Configuração do Escopo (Scope):** Definição da faixa de endereços IP atribuíveis, máscara de sub-rede e tempo de concessão (_Lease Time_).
- [x] **4. Definição das Opções de Escopo (Scope Options):** Configuração dos parâmetros globais distribuídos aos clientes, incluindo _003 Router (Gateway Padrão)_ e _006 DNS Servers_.
