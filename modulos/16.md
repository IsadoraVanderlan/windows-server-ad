## 💻 Aula 16: Configuração Avançada do Servidor DNS e Forwarders

Nesta etapa, foi realizada a otimização do serviço **DNS Server**, focando na resolução de nomes externos e criação de zonas avançadas de rede.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Configuração de DNS Forwarders (Encaminhadores):** Apontamento de servidores DNS externos (ex: Cloudflare `1.1.1.1` ou Google `8.8.8.8`) para resolução rápida de domínios públicos.
- [x] **2. Criação de Zonas de Pesquisa Inversa:** Implementação de zonas PTR (_Pointer_) para permitir a tradução de endereços IP em nomes FQDN.
- [x] **3. Criação de Registros DNS de Teste:** Cadastro manual de registros do tipo `A`, `CNAME` e `PTR` para homologação do serviço local.
- [x] **4. Validação do Serviço via Terminal:** Execução de testes de diagnóstico utilizando a ferramenta `nslookup` para validar a resolução direta e inversa.
