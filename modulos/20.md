## 💻 Aula 20: Configuração do Servidor de Impressão e Impressora via GPO

Nesta etapa, foi centralizado o serviço de impressão no Windows Server e automatizada a distribuição de impressoras para os usuários via GPO.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Instalação da Role Print and Document Services:** Configuração da função de Servidor de Impressão no Server Manager.
- [x] **2. Adição e Compartilhamento de Impressoras:** Instalação de drivers e criação de fila de impressão compartilhada no domínio.
- [x] **3. Criação de GPO para Mapeamento Automático:** Configuração de diretiva em _User Configuration > Preferences > Control Panel Settings > Printers_.
- [x] **4. Teste de Distribuição:** Acesso à estação cliente para confirmar a presença da impressora mapeada automaticamente sem ação do usuário.
