## 💻 Aula 21: Gerenciamento do Firewall do Windows via GPO

Nesta etapa, foi padronizada a segurança de rede dos computadores do domínio através da gestão centralizada do **Windows Defender Firewall via GPO**.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Criação de GPO de Segurança de Firewall:** Estruturação de política em _Computer Configuration > Windows Settings > Security Settings > Windows Firewall with Advanced Security_.
- [x] **2. Padronização de Perfis de Rede:** Definição de regras globais de entrada (_Inbound_) e saída (_Outbound_) para os perfis _Domain_, _Private_ e _Public_.
- [x] **3. Liberação de Portas e Exceções Corporativas:** Criação de regras personalizadas para portas de serviços (ex: RDP `3389`, ICMP/Ping) e programas corporativos.
- [x] **4. Bloqueio de Alteração Local:** Travamento do console local do Firewall para impedir que usuários comuns desativem a proteção da máquina.
