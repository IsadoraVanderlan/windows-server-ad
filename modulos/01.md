## 🖥️ Aula 01: Virtualização e Provisionamento de Servidor com Hyper-V

Nesta etapa, foi realizada a preparação do ambiente de virtualização local utilizando o **Hyper-V**, permitindo a criação, isolamento e provisionamento de uma Máquina Virtual (VM) para rodar o Windows Server.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Habilitação do Hyper-V:** Ativação do recurso de hypervisor nativo no sistema operacional host (gerenciador de hipervisor tipo 2/1.5).
- [x] **2. Configuração do Comutador Virtual (Virtual Switch):** Criação e ajuste das placas de rede virtuais para comunicação entre o host, a VM e a internet (External / Internal / Private Network).
- [x] **3. Criação da Máquina Virtual (VM):** Definição das configurações de hardware virtual:
  - **Geração da VM:** Escolha da Geração 2 (suporte a UEFI, Secure Boot e VHDX dinâmico).
  - **Memória RAM:** Alocação de memória (com uso de Memória Dinâmica habilitado/desabilitado).
  - **Disco Enrijecido Virtual (VHDX):** Mapeamento do tamanho e tipo de armazenamento virtualizado.
- [x] **4. Mapeamento da ISO:** Vinculação da imagem `.iso` do Windows Server à unidade de DVD virtual para boot de instalação.
- [x] **5. Instalação do Sistema Operacional:** Execução do wizard de instalação do Windows Server (definição de linguagem, partição de disco e tipo de instalação Desktop Experience / Server Core).
- [x] **6. Instalação dos Serviços de Integração (Guest Services):** Garantia da comunicação fluida de drivers, sincronização de horário e recursos entre o sistema host e a VM convidada.
- [x] **7. Criação de Ponto de Verificação (Checkpoint / Snapshot):** Salvamento do estado inicial limpo da máquina virtual para permitir restaurações rápidas antes de alterações críticas.
