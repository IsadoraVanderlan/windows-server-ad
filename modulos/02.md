## 📚 Aula 02: Pós-Instalação e Hardening do Servidor

Nesta etapa, foi realizada a checklist de configuração inicial, segurança básica e otimização do sistema operacional (Windows Server) para garantir estabilidade antes da promoção de serviços.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Windows Update:** Atualização do sistema operacional com os últimos pacotes de segurança e correções da Microsoft.
- [x] **2. Instalação de Agentes:** Configuração dos agentes corporativos de gerenciamento/monitoramento local.
- [x] **3. Nome do Host (Hostname):** Alteração do nome padrão do servidor para uma nomenclatura padronizada e identificável na rede.
- [x] **4. Configuração de Rede:** Ajuste de endereçamento IP (definição de IP Estático, Máscara de Sub-rede, Gateway e DNS).
- [x] **5. Domínio (Workgroup / Domain):** Verificação do status de adesão ao domínio (`No domain` / Workgroup inicial antes da promoção a Controlador de Domínio).
- [x] **6. Senha do Administrador Local:** Definição e alteração da senha da conta _Administrator_ local para atender aos requisitos de complexidade e segurança.
- [x] **7. Configuração do Firewall:** Ajuste e definição de regras de entrada/saída no Windows Firewall para tráfego seguro.
- [x] **8. Configuração de Antivírus:** Verificação e ativação da proteção em tempo real (Windows Defender / Antivírus corporativo).
- [x] **9. Opções de Desempenho:** Ajuste das configurações de efeitos visuais e gerenciamento de memória virtual (Paging File) com foco em performance de servidor.
- [x] **10. Hora e Data (NTP):** Ajuste do fuso horário correto e sincronização do relógio com servidor NTP para evitar erros de autenticação em rede.
- [x] **11. Agente de Monitoramento:** Verificação do status e comunicação das métricas de saúde e recursos do sistema.
- [x] **12. Limpeza do Sistema:** Remoção de arquivos temporários e resíduos de instalação para otimização de espaço em disco.
- [x] **13. Reinicialização (Restart):** Reboot do servidor para aplicar todas as alterações de nome, atualizações de sistema e políticas de rede.
