## 💻 Aula 15: Reservas de IP no DHCP por MAC Address

Nesta etapa, foi configurado o recurso de **Reserva de DHCP**, garantindo o mapeamento de IP estático baseado no endereço físico de placa de rede (_MAC Address_) para dispositivos específicos.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Identificação do Endereço MAC:** Coleta do endereço físico (_Physical Address_) dos dispositivos que exigem IP fixo (impressoras, servidores ou estações específicas) via `getmac` ou `ipconfig /all`.
- [x] **2. Criação de Reservas no Console DHCP:** Cadastro dos IPs reservados vinculados aos respectivos MAC Addresses dentro da seção _Reservations_ do escopo ativo.
- [x] **3. Definição de Opções Exclusivas de Reserva:** Configuração opcional de parâmetros personalizados de rede específicos para as máquinas reservadas.
- [x] **4. Homologação da Atribuição Fixa:** Execução dos comandos `ipconfig /release` e `ipconfig /renew` na máquina cliente para validar a entrega consistente do IP reservado.
