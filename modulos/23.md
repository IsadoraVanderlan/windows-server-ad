## 💻 Aula 23: Hardening: Habilitando a Lixeira do Active Directory

Nesta etapa, foi aplicado um processo de _hardening_ habilitando a **Active Directory Recycle Bin** para proteção contra deleção acidental de objetos do diretório.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Validação do Nível Funcional do Domínio:** Verificação dos pré-requisitos de infraestrutura para suporte ao recurso de Lixeira.
- [x] **2. Ativação do Recurso da Lixeira:** Habilitação do recurso _Enable Recycle Bin_ através do _Active Directory Administrative Center (ADAC)_ ou PowerShell.
- [x] **3. Simulação de Exclusão de Objeto:** Exclusão proposital de uma conta de usuário de teste para validação de retenção.
- [x] **4. Procedimento de Restauração em Tempo Real:** Execução do restore do objeto deletado mantendo o mesmo `ObjectGUID`, permissões e membros de grupos intactos.
