## 💻 Aula 13: Ingressando Estações Windows no Domínio

Nesta etapa, foi executada a integração de computadores clientes (_Windows 10/11_) ao domínio corporativo do Active Directory, centralizando o controle de autenticação da máquina.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Validação de Conectividade e Resolução DNS:** Configuração da placa de rede da estação de trabalho para utilizar o servidor DNS do Active Directory como primário.
- [x] **2. Alteração das Propriedades do Sistema:** Transição do computador do modelo de trabalho em _Workgroup_ para o _Domínio_ corporativo.
- [x] **3. Autenticação de Ingresso:** Utilização de credenciais de administrador do domínio para autorizar a criação da conta de computador no diretório.
- [x] **4. Validação do Logon de Usuário de Domínio:** Execução do primeiro login na estação cliente utilizando credenciais de um usuário do AD e confirmação da criação do perfil local.
