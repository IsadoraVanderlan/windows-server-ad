## 💻 Aula 05: Instalação do Active Directory e Pré-configuração

Nesta etapa, foi realizada a preparação da infraestrutura para a implantação do **Active Directory Domain Services (AD DS)** e do serviço de resolução de nomes **DNS**.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Pré-requisitos do Controlador de Domínio:** Definição e padronização do nome do computador (_hostname_) e validação das configurações de rede estática.
- [x] **2. Instalação da Role AD DS:** Adição da função de Serviços de Domínio do Active Directory através do Server Manager.
- [x] **3. Promoção do Servidor a Controlador de Domínio (DC):** Execução do assistente de configuração para criação de uma nova floresta de domínio.
- [x] **4. Implantação e Configuração do Servidor DNS:** Instalação integrada do **DNS Server**, permitindo a localização de serviços nativos do AD e a resolução de nomes da rede interna.
