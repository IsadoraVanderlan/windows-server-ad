## 💻 Aula 12: Gerenciamento Remoto do AD via RSAT

Nesta etapa, foi realizada a implantação do **RSAT (Remote Server Administration Tools)** em uma estação de trabalho para viabilizar a administração segura e remota do Active Directory.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Instalação das Ferramentas RSAT:** Adição do recurso _RSAT: Active Directory Domain Services and Lightweight Directory Services Tools_ na estação cliente Windows.
- [x] **2. Validação dos Consoles de Administração:** Acesso remoto aos consoles _ADUC (`dsa.msc`)_, _ADAC_, _DNS Manager_ e _Group Policy Management_ a partir da máquina local.
- [x] **3. Teste de Operações de Gerenciamento:** Execução de tarefas administrativas (criação de usuários e consulta de objetos) sem a necessidade de sessão RDP direta no servidor controlador de domínio.
- [x] **4. Validação de Princípio do Menor Privilégio:** Homologação do gerenciamento remoto utilizando credenciais administrativas específicas do domínio.
