## 💻 Aula 26: Backup e Restauração do Estado do Sistema

Nesta etapa, foi implementada a rotina de proteção do Active Directory através do backup do **System State** utilizando a ferramenta nativa **Windows Server Backup**.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Instalação da Feature Windows Server Backup:** Adição do recurso de backup nativo via Server Manager ou PowerShell.
- [x] **2. Execução de Backup do System State:** Criação de cópia de segurança completa do estado do sistema (incluindo o banco do AD `ntds.dit`, registro, `SYSVOL` e arquivos de boot).
- [x] **3. Agendamento e Armazenamento do Backup:** Definição de local seguro para gravação da cópia de segurança em disco secundário ou volume dedicado.
- [x] **4. Documentação do Processo de Disaster Recovery:** Mapeamento dos passos para restauração autoritativa e não-autoritativa utilizando o modo DSRM em caso de desastre.
