## 💻 Aula 22: Mapeamento de Discos e Unidades de Rede via GPO

Nesta etapa, foi automatizada a criação de unidades de disco de rede (letras de unidade ex: `Z:`, `H:`) para os usuários do domínio utilizando as preferências de GPO.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Configuração de Preferences de Mapeamento:** Criação de política em _User Configuration > Preferences > Windows Settings > Drive Maps_.
- [x] **2. Definição do Caminho UNC e Letra de Unidade:** Vinculação do diretório compartilhado (`\\servidor\pasta`) à letra de unidade correspondente.
- [x] **3. Aplicação de Item-Level Targeting:** Filtragem avançada para garantir que apenas membros de grupos específicos (ex: `GRP_Financeiro`) recebam a unidade correta.
- [x] **4. Homologação no Explorer:** Logon na estação de trabalho para validar o surgimento automático do disco mapeado no Meu Computador.
