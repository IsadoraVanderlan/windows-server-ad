## 💻 Aula 25: Auditoria de Eventos e Logs de Acesso (Event Viewer)

Nesta etapa, foi configurada a auditoria de segurança centralizada para monitoramento de eventos críticos de autenticação e modificação de objetos na rede.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Configuração de GPO de Auditoria de Segurança:** Ativação do rastreamento em _Audit Logon Events_, _Audit Account Management_ e _Audit Directory Service Access_.
- [x] **2. Análise de Eventos no Event Viewer:** Monitoramento do log de _Security_ no Visualizador de Eventos para identificação de falhas e sucessos de acesso.
- [x] **3. Mapeamento de Event IDs Críticos:** Identificação de eventos padrão de auditoria (ex: `4624` Logon Bem-Sucedido, `4625` Falha de Logon, `4720` Conta Criada).
- [x] **4. Filtro e Criação de Exibições Personalizadas:** Configuração de visões customizadas no Event Viewer para agilizar a resposta a incidentes de segurança.
