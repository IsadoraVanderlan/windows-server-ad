## 💻 Aula 03: Funções, Recursos e Gerenciador de Servidores

Nesta etapa, foi realizada a exploração do **Gerenciador de Servidores (Server Manager)** para entender a arquitetura de serviços do Windows Server, diferenciando o papel do servidor das suas ferramentas de suporte.

### 📋 Checklist de Atividades (Tasks)

- [x] **1. Navegação pelo Gerenciador de Servidores:** Reconhecimento do painel principal (Dashboard) para monitoramento de eventos, serviços e desempenho do servidor.
- [x] **2. Entendimento do Conceito de Roles (Funções):** Identificação dos papéis principais que o servidor pode assumir na rede (ex: Active Directory, DNS Server, DHCP Server e Web Server).
- [x] **3. Entendimento do Conceito de Features (Recursos):** Mapeamento das ferramentas auxiliares e utilitários de suporte (ex: PowerShell, RSAT e Criptografia BitLocker).
- [x] **4. Gerenciamento do Sistema:** Utilização do assistente de adição e remoção de funções e recursos para adequar o ambiente às necessidades da infraestrutura.
